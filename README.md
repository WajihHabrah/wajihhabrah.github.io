# WajihHabrah.github.io

Personal engineering portfolio of Wajih Habrah, available in English and Arabic.

- English: `/` and `/projects/`
- Arabic: `/ar/` and `/ar/projects/`

Both language versions share the same images, documents, styles, scripts and
interactive 3D model. Language-switch links and `hreflang` metadata connect each
English page with its Arabic equivalent.

## Apply this update

Copy the contents of this package into the root of the existing
`WajihHabrah.github.io` repository and allow the matching files to be replaced.
Keep the repository's existing images, documents, model and unchanged scripts;
this package contains only the files that were added or modified for the
bilingual version.
